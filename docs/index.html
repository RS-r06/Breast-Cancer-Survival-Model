Breast Cancer Survival Model

Not for clinical use. This is a learning project built on research data from women treated between 1978 and 1993. Treatment has improved a great deal since then, so its numbers are too pessimistic for anyone today. Never use it to make or discuss a real decision.

How good is the model?

Built with a Cox proportional hazards model on women from the Rotterdam tumour bank, then tested, unchanged, on 686 women from the German Breast Cancer Study Group trial. Method, statistics and code on GitHub.
